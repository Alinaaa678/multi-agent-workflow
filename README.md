# 多智能体协作开发平台

本仓库用于六人团队协作开发多智能体讨论与开发平台。项目采用“共享黑板 + 主持人编排 + 专业 Agent + 独立质量验收”的结构，校园失物招领系统作为贯穿案例。

## 项目范围

平台分为需求讨论、需求确认、设计规格、任务编排、Agent 接入、交互展示和质量共识等工作块。每个工作块在独立分支中开发，通过 Pull Request 合并到 `integration`，集成验证通过后再进入 `main`。

当前工作块：

- B01：需求与范围确认
- B02：讨论控制器与流程编排
- B03：共享黑板与状态数据
- B04：Agent 接入与模型适配
- B05：交互展示与结果导出
- B06：质量共识、测试证据与缺陷闭环

## 分支约定

- `main`：稳定的项目主线，只接受经过集成验收的合并。
- `integration`：跨工作块集成分支，用于联调和回归测试。
- `bXX-*`：各工作块的长期开发分支。
- `bXX-*/task-*`：单项任务的短期分支。

不要直接向 `main` 推送。提交应关联任务编号、需求引用、输入版本、测试命令和证据；接口变更需要通知所有消费方。

## 快速开始

各工作块的运行方式和依赖写在对应目录的 README 中。项目设计、接口约定、提交规范和集成流程见 [`docs/`](docs/)。

## 质量要求

每个可合并的 PR 至少应包含可复现的测试命令和结果。模型回复、文件存在或多数意见不能替代测试证据。涉及共享接口的修改必须在 `integration` 上重新运行受影响的回归测试。
