# 项目总览

## 目标

本项目实现一个可追溯的多智能体协作开发平台：从需求讨论开始，经需求确认、设计规格、任务拆分和 Agent 执行，最终由独立质量环节验收并形成可复现交付物。

## 共同约束

1. 需求、设计、契约和任务必须保留版本号。
2. 黑板中的过程状态与校园案例的业务数据分开保存。
3. Agent 只在授权任务边界内读写，不直接越权修改其他工作块状态。
4. 失败通过结构化事件反馈给编排器，不能用自然语言声明代替证据。
5. 需求或共享接口变更后，必须重新验证受影响产物。

## 交付路径

`需求基线 → 设计规格 → 任务计划 → Agent 产物 → 独立验收 → integration 联调 → main 发布`

## 版本与证据

提交、测试报告和产物都应绑定 `spec_version`、`contract_version`、`plan_version`、`task_id`、`attempt_id` 和输入快照。具体字段以各工作块的接口文档为准。
